# MemoReMember Android 업데이트

**0.20 · 2026-11-20** · [최신 APK 다운로드](https://raw.githubusercontent.com/jayck87/MemoRemember-updates/main/TravelGalpi-0.20.apk)

기존 여행갈피에서 첫 화면의 **설정 → 업데이트 확인**을 누르거나 위 APK를 받아 기존 앱 위에 설치하세요. Android 설치 승인이 필요합니다.

## 0.20에서 달라진 점

- 첫 화면의 두 R이 한 줄의 **Memo Re Member**로 합쳐집니다. 위쪽은 여행 기록, 아래쪽은 아이의 창작물입니다.
- 지도의 첫 보기에 남한 본토와 제주도를 담았습니다. 지도를 확대하면 방문 핀과 여행명이 차례로 보입니다. 여행 목록 아래의 손잡이를 위아래로 끌면 높이가 바뀝니다.
- **전체보기 → 달력 아이콘**에서 날짜별로 다녀온 여행을 볼 수 있습니다. 상세 화면의 집 아이콘은 첫 화면으로 돌아갑니다.
- 여행 계획의 방문지를 열고 **네이버 장소·리뷰**를 누르면 장소를 검색할 수 있습니다. 좌표가 있는 방문지는 네이버 지도에서 자동차 이동 경로를 확인할 수 있습니다.
- 여행 사진과 작품을 열면 **다운로드**로 휴대폰의 Download/MemoReMember 폴더에 사본을 저장하고 **외부 공유**로 받을 앱을 고를 수 있습니다.

## 0.19에서 달라진 점

- 지도 우측의 여행 목록을 작게 다듬었습니다. Year와 Month에서 기간을 고르고 아래 조절바로 높이를 바꿀 수 있습니다.
- 지도나 목록 하단의 **+**에서 다녀온 기록 또는 여행 계획을 고르세요. 달력에서 같은 날짜를 두 번 누르면 하루 여행이 됩니다. 두 번째 날짜가 앞서면 그날부터 종료일을 다시 고릅니다.
- 상세 화면에서 여행 제목과 기간을 눌러 수정할 수 있습니다. 새 방문 기록에는 날짜와 후기를 입력하고 **현재 위치 찾기 → 이 위치 선택 → 저장**으로 장소를 붙일 수 있습니다. 예전에 입력한 방문 시각과 사진 배정은 유지됩니다.
- ReMember에는 아이의 출생년도가 표시됩니다. 작품을 열고 **작품 연도 수정**에서 휠을 움직여 제작 연도를 바꿀 수 있습니다. 여행과 작품 사진은 기기에서 관리합니다.

## 0.18에서 달라진 점

- **Memo**를 누르면 여행 지도가 열립니다. 빨간 핀은 기록, 초록 핀은 계획입니다. 지도 우측에서 연도와 월을 고르면 현재 화면에 방문지가 있는 여행을 볼 수 있습니다. **전체보기**에는 위치가 없는 여행도 나옵니다.
- 여행 티켓을 누르면 상세 화면이 열립니다. 사진 수를 누르면 분류됨·미분류 사진을, 방문 카드를 누르면 해당 장소의 기록과 사진을 볼 수 있습니다.
- **Member**를 누르면 아이의 작품과 편지를 촬영하거나 기존 사진에서 가져올 수 있습니다. **설정 → 아이의 출생년도**를 입력하면 촬영 연도 옆에 그해의 나이를 표시합니다. 작품을 열어 제작 연도를 수정할 수 있습니다.
- 작품 사진 사본은 이 휴대폰의 앱 저장 공간에 보관합니다. 설정의 **기록 백업·복원**은 여행 기록과 사진 배정용입니다.

기존 APK와 동일한 서명 인증서, 앱 내 업데이트 주소, 공개 다운로드의 SHA-256을 확인했습니다. Android 16 에뮬레이터에서는 합성 사진으로 여행 배정, 카메라 결과 처리와 작품 저장을 검증했습니다.

## v0.13 변경

사진이 배정된 방문은 바로 제거할 수 없도록 보호합니다. 먼저 사진을 다른 방문지 또는 여행 전체로 재분류해 주세요. 사진이 없는 방문은 기존처럼 제거할 수 있습니다. UI 스타일은 유지했습니다.

## v0.14 변경

방문 수정 전 자동 분류가 달라지는 사진 수를 안내합니다. 직접 지정한 배정과 예전 방문 시간 후보에서 확인한 배정은 유지합니다. 확인 화면에서 ‘수정 계속’을 선택하면 방문 변경은 저장하지 않습니다. 스타일 변경과 원본 사진 삭제 기능은 포함하지 않습니다.

## v0.15 화면 정리

- 홈: 여행 목록과 새 여행. 설정은 화면 위에서 바로 열 수 있습니다.
- 여행: 방문 기록과 사진 정리. 여행 편집·나누기는 더 보기에 있습니다.
- 사진 정리: 사진 추가와 미분류·전체·여행 전체·날짜 밖 사진을 한곳에서 확인합니다.
- 설정: 백업·복원, 업데이트, 서비스 안내와 고급 점검을 모았습니다.
- 주요 행동만 진한 녹색으로 표시합니다. 기존 여행·사진 배정과 저장 형식은 유지합니다.

v0.15부터 수동 업데이트 확인은 홈의 **설정 → 업데이트 확인**에서 진행합니다. 앱 실행 시 자동 확인은 계속 동작합니다.

## v0.16 Google 지도 메인

지도 핀을 선택하면 아래 여행 카드가 바뀌고, 카드에서 기록을 열 수 있습니다. 위치가 없는 여행도 여행 목록에서 확인할 수 있습니다. 가로 화면에서는 카드가 지도 옆에 표시됩니다. 방문 시간은 ‘이 장소에 도착한 시간 / 이 장소에서 떠난 시간’으로 표시합니다. 기존 여행·사진 배정과 원본은 유지합니다.

빌드와 자동 검사는 통과했습니다. 실제 기기의 지도 타일 표시·API 인증과 기존 데이터 보존은 설치 후 확인이 필요합니다. 파일 크기는 약 36.5MB입니다.

## v0.17 심플 지도 스타일

지도 배경의 상호·관광지·교통 아이콘과 작은 길 이름을 숨기고 주요 도로·지명과 여행 핀이 보이도록 정리했습니다. 배경은 옅은 회색·녹색, 물은 연한 청회색으로 표시합니다. 앱 내부 JSON 스타일을 사용하며 지도 데이터·Google 출처 표시는 유지합니다. 여행·사진 배정과 지도 시작 위치·확대 범위는 변경하지 않습니다. 실제 기기의 색상·라벨 표현은 설치 후 확인해 주세요.
