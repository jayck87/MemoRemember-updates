# 여행갈피 Android 업데이트

[최신 APK 다운로드](https://raw.githubusercontent.com/jayck87/MemoRemember-updates/main/TravelGalpi-0.12.apk)

현재 최신 버전: **0.12** (2026-11-18)

1. 기존 앱을 삭제하지 않고 APK를 내려받아 덮어 설치하세요.
2. 설치가 대기 상태라면 여행갈피를 종료한 후 설치를 다시 진행하세요.
3. 설치 후 앱의 ‘업데이트 확인’을 눌러 ‘현재 설치 가능한 새 버전이 없습니다’가 표시되는지 확인하세요.

v0.12는 한 번 수동 설치해야 합니다. 다음 버전부터 앱 실행 시 새 버전을 확인하고 다운로드를 제안합니다. Android 설치 승인은 사용자가 직접 진행합니다. 자동으로 조용히 설치되지는 않습니다.

기존 여행·사진 배정은 업데이트 시 유지합니다. 휴대폰 원본 사진을 삭제하는 기능은 포함하지 않습니다. 설치 후 기존 기록과 사진 수를 확인하세요.

이 저장소에는 배포 APK, 버전 안내와 해시만 포함합니다. 소스 코드·서명 개인키·사용자 여행 기록·사진은 포함하지 않습니다.

빌드 검증: JVM 361개 조건, CLI 10개 시나리오, Android 16 합성 데이터 회귀 13단계와 Google SDK 포함 빌드 통과. 이 APK는 Google 키가 없는 기본 빌드입니다. 실기기 업데이트 설치 흐름은 추가 확인이 필요합니다.
